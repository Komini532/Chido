## 「<ruby>地道<rt>ちどう</rt></ruby>」とは？

我々に数多の恩恵を齎す存在である、太陽。

この世界では、太陽が我々に与える恩恵や太陽そのものを指して、<ruby>**天道**<rt>てんどう</rt></ruby>と呼びます。

<ruby>**地道**<rt>ちどう</rt></ruby>は、大地の恩恵や、ヒトも含めた動物が生む恩恵を指す語です。

草木が芽生え、森を成す。卵から雛が孵り、成長し、また卵を産む。ヒトが文明を築く。

地道は、積み重ねて形成された大地の恵みとして通ずるものです。
